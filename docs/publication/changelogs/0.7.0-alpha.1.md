- Long recordings finalize automatically when leaving a world. Recording journals
  allow recoverable unfinished segments to be exported on the next recorder start.
- Recently deleted clips, bulk restore and undo preserve the video and clip metadata.
- Ctrl+F opens library search, Delete moves selected clips to recently deleted,
  Ctrl+Z undoes a deletion and Ctrl+E opens export controls.
- Minimal, Soft and Electric feedback styles with separate button and notification
  volume controls. Minimal is the default.
- Corrected floating toolbar click priority and long-recording elapsed time.
- Lower-priority FFmpeg workers on supported Unix systems, a BGRA capture fallback
  for GPUs without the NV12 conversion path and improved encoder format selection.

Use the build for your exact Minecraft version. Each uploaded artifact is checked
in a fullscreen Minecraft session and produces a playable MP4 before publication.
FFmpeg is still required separately. Link sharing still requires a configured
upload service. Recovery depends on intact source segments and writable storage;
it cannot guarantee recovery from every crash or disk failure.
