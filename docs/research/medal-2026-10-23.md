# Medal research and Volt priorities — 2026-10-23

This is a product comparison and development checklist, not a claim that Volt
already outperforms Medal. No matched Windows head-to-head benchmark has run.

## Primary references

- [Getting started on Windows](https://support.medal.tv/support/solutions/articles/48000959661-getting-started-with-medal-on-windows): game detection, F8 replay, library organization, recording/audio/hotkey settings and custom game profiles.
- [Recording methods](https://support.medal.tv/support/solutions/articles/48001157616): replay, screenshots, full sessions and desktop capture are distinct workflows.
- [Advanced editor](https://support.medal.tv/support/solutions/articles/48001275437/): adjustable resolution, aspect ratio, FPS and bitrate; large projects can consume substantial memory.
- [Long-recording trimming](https://support.medal.tv/support/solutions/articles/48001159728-how-to-create-clips-from-a-long-recording): bookmarks, multiple exports, keyboard navigation and trimming shortcuts.
- [Sound alerts](https://support.medal.tv/support/solutions/articles/48001271329-sound-alerts-faq): separate alert controls and configurable clipping sounds.
- [Performance troubleshooting](https://support.medal.tv/support/solutions/articles/48000922094/create_ticket): encoding, capture quality and resource contention affect recording; no universal zero-impact guarantee.

## Make Minecraft workflows easier

| Workflow | Published Volt 0.6 | Development 0.7 | Remaining validation/work |
| --- | --- | --- | --- |
| Save a recent moment | F8, 15–120s, local MP4 | Durable export intent | Abrupt process-termination runtime test |
| Keep a long session | F9, F7 markers; manually stop before leaving | Stop/leave automatically finalizes; orphan segments recover on next recorder startup | Fullscreen gameplay/close check |
| Clean up automatic clips | Favorites, filters and bulk selection | Local recently-deleted collection, bulk move/restore and undo | Real UI regression check |
| Identify important Minecraft moments | Confirmed melee combos, selected PvP/adventure events | Preserves event metadata during recovery | More real-server gameplay coverage |
| Tune notification sounds | Separate button/notification volume | Minimal, Soft and Electric styles; preview identifies itself correctly | User preference remains subjective |
| Protect game performance | GPU NV12, persistent PBOs, bounded queues and quality caps | Lower-priority Unix FFmpeg workers when available | Matched performance testing; Windows native priority still unchanged |
| Share a clip | Custom upload service required | Unchanged | Accountless hosting or a clearly named optional provider needs a separate implementation |
| Install dependencies | External FFmpeg path | Unchanged | A convenient, verified engine installer remains valuable |

The intended advantage is a focused Minecraft tool: useful event hooks, readable
in-game controls and local-first operation. A social feed, multi-track montage
editor or every Medal feature should not be claimed when absent.

## Validation gates

- Every advertised Minecraft target needs its own exact-API compile and playable recording check.
- Preserve video bytes and metadata when moving/restoring clips; reject overwrites.
- Preserve orphan source segments if recovery fails; recover committed clips idempotently.
- Keep fullscreen UI controls readable and route floating actions ahead of underlying cards.
- Keep audio short and non-tonal; allow independent mute/volume/style selection.
- Report capture conditions and limitations alongside measurements.
